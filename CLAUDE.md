# Claude entry point

Read and follow `AGENTS.md` before working on DenDenMushi. It contains the
installation workflow, automatic/user-assisted steps, privacy and hardware
constraints, and verification commands.

For installation requests, start with `bash scripts/doctor.sh` and
`docs/INSTALL.md`. Carry out authorized setup and explain what needs the
user; do not just paste the README and stop.

Finish with a normal `DenDenMushi.app` installed in Applications and opened
from there. Run the build yourself; do not ask the user to install or launch
the app by typing Terminal commands. Complete the native audio installer with
the user's macOS approvals, and verify both Wi-Fi audio devices appear.
