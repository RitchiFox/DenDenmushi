У налаштуваннях «Передавання звуку» вибери Bluetooth або Wi-Fi. Для Wi-Fi один раз встанови аудіопристрої кнопкою в налаштуваннях та онови Pi. У Telegram вибери DenDenMushi Wi-Fi Microphone і DenDenMushi Wi-Fi Speakers. Вибір зберігається; перемикання коротко перериває звук.

# DenDenMushi

## Підключення

1. Увімкни равлика й Bluetooth на Mac. Обидва пристрої мають бути в одній Wi-Fi мережі.
2. Натисни **Підключити**. Програма сама знайде равлика через Bluetooth, а відео передаватиме через Wi-Fi.
3. На новому Mac один раз введи **пароль або код равлика**. Це не пароль MacBook і не пароль користувача Raspberry Pi. Надалі програма використовує збережений доступ.
4. У Meet або Telegram вибери **OBS Virtual Camera**. Встановлений OBS має бути у папці Applications; він працюватиме у фоні.

У програмі доступний живий перегляд до 15 кадрів/с; у дзвінок передається повне відео 720p / 30 кадрів/с.

## Звук

Камера й звук розташовані на одному екрані. Один раз спаруй равлика з Mac кнопкою **Підключити звук через Bluetooth**. Далі **Підключити** сама запускає камеру й підключає динаміки равлика. У дзвінку вибери **DenDenMushi** або системний аудіовихід за замовчуванням. Якщо звук не підключився, натисни **Повторити звук**; камера продовжує працювати.

Повзунки **Гучність динаміків равлика** та **Рівень мікрофона равлика** керують USB-картою на Pi. Пересунь і відпусти повзунок, щоб записати рівень. 0 дБ — без приглушення, від’ємні значення тихіші. З оновленою службою мікрофон можна підсилити до +20 дБ; почни з 0 дБ. Підсилюється також шум, тому при спотворенні зменш рівень. Кнопка поруч вимикає/вмикає відповідний канал. Значення зчитуються з Pi й не скидаються при підключенні; кнопка оновлення перечитує їх. Гучність Mac також впливає на звук.

OBS Virtual Camera передає лише відео. Після оновлення Pi ввімкни **Мікрофон равлика**, щоб спробувати двосторонній Bluetooth-звук. У Telegram / Meet вибери **DenDenMushi** або системний мікрофон за замовчуванням. Початок запису в Telegram може бути потрібний для відкриття каналу. У цьому режимі звук моно, телефонної якості. Вимкнення перемикача повертає стереозвук і попередній мікрофон, якщо ти не вибрав інший. Програма не записує розмову у файл. Перевір голос коротким пробним записом.

Для старої служби програма запропонує одноразове **Оновити Pi**. Власник вводить пароль акаунта Pi у вікні оновлення; для подальших підключень пароль не потрібен.

## Мова

У **Налаштування → Мова програми** обери **Українська**, **Čeština** або **English**. Зміна діє одразу й зберігається на цьому Mac. Назви пристроїв і паролі залишаються незмінними. Системні вікна дозволів macOS використовують системні налаштування мови застосунку.

## Пароль, Wi-Fi та скидання

- **Змінити пароль равлика** задає пароль для додавання Mac. Для запису зміни потрібен пароль акаунта Pi; він не зберігається. Пароль входу в сам Pi не змінюється.
- **Код для іншого Mac** копіює доступ для людини, якій ти дозволяєш підключення. Не публікуй цей код.
- **Змінити Wi-Fi равлика** передає нову мережу через Bluetooth. Pi 3 потрібна мережа 2,4 ГГц. Гостьова ізоляція може блокувати відео до Mac.
- **Скинути підключення цього Mac** видаляє ключ камери цього Mac на Pi та збережене локальне підключення. Код потрапляє в буфер обміну для повторного першого підключення. Мережа й сервіси Pi залишаються налаштованими.

## Новий Pi

Власник один раз встановлює служби через **Налаштування → Підготовка нового Pi / оновлення сервісу**. Pi уже має бути доступний через SSH у локальній мережі. Потрібні його адреса, користувач і пароль акаунта. Іншим користувачам готового равлика достатньо його пароля або коду.

**Зупинити** вимикає камеру. Закриття вікна залишає програму в меню-барі; **Завершити DenDenMushi** зупиняє керовані процеси й закриває програму.

## Автоматична тиша

Після оновлення Pi вихід вимикається приблизно через 2 секунди після припинення Bluetooth-потоку й повертається з початком відтворення. Ручний mute та гучність зберігаються окремо. Якщо програма продовжує передавати тишу всередині активного потоку, вихід залишається ввімкненим. Для оновлення один раз натисни «Оновити Pi» і введи пароль власника у вікні програми.

## Динаміки та мікрофон через USB-карту (v0.5.4)

Вхід підсилювача підключається до зеленого роз’єму USB-карти Alza, мікрофон — до червоного роз’єму цієї самої карти. Онови службу через «Підготувати мій Pi», потім натисни «Підключити». Регулятор динаміків і автоматичне приглушення керують USB-виходом; регулятор мікрофона — USB-входом. Для дзвінка додатково ввімкни «Мікрофон равлика» (v0.6.0, експериментальний режим).

Якщо Mac не показує мікрофон після перемикання зі стереозвуку, програма один раз перепідключить лише DenDenMushi. Звук коротко перерветься, спарювання збережеться. Якщо відновлення не допоможе, натисни «Повторити звук».
