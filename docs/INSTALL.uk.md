# Встановлення DenDenMushi

Потрібна macOS 14 або новіша. Перевірено Apple Silicon; Intel ще не перевірено.
Для Windows/Linux десктопної версії немає. Pi — окремий пристрій, застосунок
керування працює на Mac.

## Через Codex або Claude Code

Відкрий папку репозиторію в агенті та напиши:

> Встанови DenDenMushi за AGENTS.md і docs/INSTALL.uk.md. Перевір, що вже
> встановлено, завантаж потрібні залежності та збери програму. Виконай доступні
> кроки автоматично й поясни, які дозволи та дії потрібні від мене. Не рухай
> сервами та не запускай звукові тести без мого прохання.

Якщо коду ще немає, попроси спочатку клонувати
`https://github.com/TimeSkipe/DenDenmushi.git` у нову папку.
Codex читає `AGENTS.md`, Claude — `CLAUDE.md`, який веде до тих самих правил.
Агент має працювати на твоєму Mac із доступом до термінала. Звичайний чат без
інструментів лише пояснюватиме кроки.

| Автоматично в межах запиту на встановлення | Твоя участь |
| --- | --- |
| Перевірка ОС, інструментів, OBS та аудіопристроїв | Завершення діалогів Apple і системних дозволів |
| Завантаження коду, залежностей, збірка й перевірка | Адреса та ім'я користувача власного Pi |
| Установлення дозволених компонентів | Пароль у захищеному вікні програми |
| Перевірка служб і підключення | Підключення обладнання, вибір пристроїв дзвінка, перевірка звуку |

## Вручну: підготуй Mac

1. Перевір macOS у ** → Про цей Mac**: потрібна версія 14+.
2. Установи [OBS Studio](https://obsproject.com/download) у **Applications / Програми**.
   Він надає OBS Virtual Camera. Дозволь його розширення камери, якщо macOS попросить.
3. У Terminal виконай `xcode-select --install` і заверши діалог Apple.
   Якщо інструменти вже встановлено, повторне встановлення не потрібне.
4. Перевір `python3 --version`. Якщо Python 3 немає, встанови його з
   [python.org](https://www.python.org/downloads/macos/).

## Завантаж і збери програму

```sh
git clone https://github.com/TimeSkipe/DenDenmushi.git
cd DenDenmushi
bash scripts/doctor.sh
python3 scripts/build-wifi-drivers.py
bash scripts/build-app.sh
open build/DenDenMushi.app
```

Збірка може зайняти кілька хвилин. Готовий застосунок:
`build/DenDenMushi.app`. Перетягни його в **Програми** через Finder, якщо хочеш.
Команди не встановлюють аудіодрайвери, не змінюють Pi і не рухають сервами.
Не запускай дві копії одночасно.

Це локальна збірка з вихідного коду. Готового підписаного й нотаризованого
релізу поки немає; вимикати захист macOS не потрібно.

## Підключи равлика

**Уже підготовлений пристрій:** увімкни його, підключи Mac до тієї ж локальної
мережі, натисни **Підключити равлика** й введи код від власника. Не потрібно
повторно встановлювати служби Pi.

**Новий власний Pi:**

1. Встанови сумісну ОС на microSD, задай власного користувача, пароль, Wi-Fi
   та SSH. Запис ОС стирає вибрану карту — уважно вибери носій.
2. Перевір SSH, камеру й звук у самій ОС. Pi 3 Model B підтримує Wi-Fi 2,4 ГГц.
3. Прочитай [SETUP.md](SETUP.md) та [HARDWARE.md](HARDWARE.md).
   При первинному налаштуванні залиш тяги механізмів серв від'єднаними.
4. У програмі відкрий **Налаштування → Підготовка нового Pi / оновлення сервісу**.
5. Введи адресу, користувача Pi із sudo та його пароль. Перевір SSH-відбиток.
6. Натисни **Підготувати мій Pi**, дочекайся завершення. Інсталятор змінює
   служби Pi. Якщо є помилка — з'ясуй її причину, не обходь перевірки.
7. Повернись на головний екран і натисни **Підключити равлика**.

Це не інсталятор ОС. Потрібні `rpicam-vid`, `ffmpeg`, `parec`, `pacat`,
`paplay`, NetworkManager, BlueZ, PipeWire/WirePlumber та сумісний kernel PWM.
Перевірений стек і обмеження наведені в [SETUP.md](SETUP.md).
У репозиторії немає готового користувача чи пароля для твого Pi.

## Налаштуй Wi-Fi-звук та дзвінок

1. У налаштуваннях вибери транспорт звуку **Wi-Fi**.
2. Установи аудіопристрої кнопкою програми; macOS може попросити пароль
   адміністратора. Це перезапускає весь звук Mac — роби поза дзвінком.
3. Дозволь мікрофон, Bluetooth і локальну мережу за запитом macOS. Для
   слідування мережі Mac може знадобитися дозвіл визначення назви Wi-Fi.
4. У Meet / Telegram вибери **OBS Virtual Camera**, **DenDenMushi Wi-Fi Microphone**
   та **DenDenMushi Wi-Fi Speakers**.
5. Почни з помірної гучності й рівня мікрофона 0 дБ. Коли можна шуміти,
   перевір короткий дзвінок. Залишкове ехо ще можливе — це прототип.

Кнопки очей і повзунок нахилу камери розташовані біля відео. Рух триває 0,5 с.
Кути підібрані для авторської конструкції: спершу відкалібруй свою без тяги.
Не підтверджуй положення, якщо фізично його не знаєш.

## Оновлення програми

Під час запуску програма перевіряє гілку `main` цього GitHub-репозиторію.
Це лише запит версії: код не встановлюється автоматично. Перевірку можна
вимкнути прапорцем у **Налаштування → Оновлення програми**.

1. Заверши дзвінок і натисни **Повністю від’єднати**.
2. Відкрий налаштування, натисни **Перевірити оновлення**.
3. Якщо є нова версія, натисни **Оновити й перезапустити**.
4. Програма закриється; Terminal завантажить вибраний коміт, збере програму
   та відкриє її. Не закривай Terminal до завершення. Потрібні інтернет,
   Python 3 та інструменти розробника; це може зайняти кілька хвилин.
5. Попередня версія залишиться поряд як `DenDenMushi-backup-….app`.

Помилка завантаження чи збірки не видаляє чинну програму. Налаштування Mac,
ключі доступу та служби Pi цей механізм не змінює. Оновлення Pi й установлення
нового аудіопакета — окремі дії через налаштування. Після локального підписання
macOS інколи повторно запитує дозволи.

Потрібен доступ на запис до папки застосунку. Якщо його немає, перенеси
програму у власну `~/Applications`. Для повернення до попередньої версії
закрий програму й відкрий збережену резервну копію. Оновлення з `main` — це
оновлення прототипу, а не канал перевірених стабільних релізів. Воно замінює
код застосунку, тому для власної модифікованої збірки оновлюй свій форк вручну.

## Якщо не працює

| Симптом | Що перевірити |
| --- | --- |
| `xcrun` / `swiftc` не знайдено | Завершення Xcode Command Line Tools |
| Немає аудіопакета при збірці | Спершу `python3 scripts/build-wifi-drivers.py` |
| Немає OBS Virtual Camera | OBS у Applications, його системний дозвіл камери |
| Pi не знаходиться | Живлення, SSH, спільна мережа, Bluetooth і Wi-Fi 2,4 ГГц для Pi 3 |
| Немає Wi-Fi-аудіопристроїв | Установлення пакета в налаштуваннях і повторне відкриття списку пристроїв дзвінка |
| Помилка `pwm-gpio` | Сумісність ядра та overlay; не вимикай перевірку |
| Ехо | Обидва Wi-Fi-пристрої у дзвінку, гучність, розташування мікрофона й динаміків |

Для допомоги вкажи macOS, модель/ОС Pi й текст помилки. Не публікуй паролі,
коди, ключі та особисті мережеві налаштування.
